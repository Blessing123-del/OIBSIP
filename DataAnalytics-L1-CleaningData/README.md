# 🚢 Titanic Data Cleaning

### Oasis Infobyte Data Analytics Internship — Task 3, Level 1

## 📌 Project Overview

This project focuses on cleaning and preparing the Titanic dataset for further analysis and modeling.

The dataset was examined to identify common data quality issues, including missing values, duplicate records, inconsistent entries, incorrect data types, and potential outliers. The goal was to transform the raw dataset into a clean, consistent, and analysis-ready dataset while preserving valid observations.

---

## 🎯 Objectives

- Improve the overall quality and consistency of the dataset.
- Identify and handle missing values appropriately.
- Check and remove duplicate records.
- Standardize categorical data and correct data types.
- Detect and evaluate potential outliers using the IQR method.
- Validate the cleaned dataset.
- Export the final analysis-ready dataset.

---

## 🔍 Project Workflow

### 1. Data Loading and Exploration

- Loaded the Titanic dataset using Pandas.
- Examined the dataset structure, columns, and data types.
- Checked the dataset for missing values and duplicate records.

### 2. Missing Value Treatment

- Identified columns containing missing values.
- Applied appropriate methods to handle missing observations.
- Ensured the cleaned dataset contained no unintended missing values.

### 3. Duplicate Records

- Checked for duplicate rows.
- Removed duplicate records where necessary to maintain data integrity.

### 4. Data Standardization

- Reviewed categorical variables for inconsistent entries.
- Standardized values where necessary.
- Corrected inappropriate or inconsistent data types.

### 5. Outlier Detection

- Used the **Interquartile Range (IQR)** method to identify potential outliers.
- Evaluated unusual observations before deciding how to handle them.
- Preserved valid observations rather than automatically removing every detected outlier.

### 6. Data Validation and Export

- Rechecked the cleaned dataset to confirm that the cleaning process was successful.
- Exported the final dataset for future analysis and modeling.
