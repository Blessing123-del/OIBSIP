
📱 Google Play Store Analysis

Oasis Infobyte Data Analytics Internship — Task 4, Level 2

«Unveiling the Android App Market Through Data.»

📌 Project Overview

This project focuses on analysing Google Play Store app data alongside user reviews to understand app categories, ratings, installations, pricing, and user sentiment.

The analysis involved cleaning and preparing real-world datasets, performing exploratory data analysis, investigating relationships between app attributes, estimating potential revenue, and analysing user sentiment to generate meaningful insights into the Android app market.

🎯 Objective

The main objective of this project was to understand the Google Play Store ecosystem and generate data-driven insights that could help developers make informed decisions when planning and launching applications.

🔎 Key Steps

1. 📂 Data Exploration

Loaded and explored the Google Play Store apps and user reviews datasets to understand their structure, features, and key characteristics.

2. 🧹 Data Cleaning & Preparation

- Handled missing values.
- Removed duplicate records.
- Corrected incorrect data types.
- Converted installation and pricing data into suitable numerical formats.
- Prepared both datasets for further analysis.

3. 📊 App Market Analysis

- Analysed app distribution across different categories.
- Examined category saturation.
- Explored rating patterns and average ratings across categories.
- Investigated the relationship between app size and installations.

4. 💰 Pricing & Revenue Analysis

- Compared free and paid applications.
- Analysed pricing patterns.
- Estimated potential revenue across different app categories.

5. 💬 Sentiment Analysis

Performed sentiment analysis on user reviews using TextBlob/VADER.

The analysis examined:

- Positive sentiment
- Negative sentiment
- Neutral sentiment

Sentiment patterns were also compared across different app categories.

6. 📈 Data Visualization

Created visualisations using Matplotlib and Seaborn to communicate key findings, patterns, and insights discovered throughout the analysis.

💡 Key Insights

The analysis provided insights into:

- Popular Google Play Store categories.
- Rating patterns across app categories.
- The relationship between app size and installations.
- Differences between free and paid applications.
- Pricing and potential revenue patterns.
- User sentiment across different app categories.

🛠️ Tools & Technologies

🐍 Python | 🐼 Pandas | 🔢 NumPy | 📊 Matplotlib | 📈 Seaborn | 💬 TextBlob/VADER | 📓 Jupyter Notebook
