
🐦 Twitter Sentiment Analysis Using NLP & Machine Learning

Oasis Infobyte Data Analytics Internship — Task 4, Level 1

«Turning Twitter text into meaningful insights.»

📌 Project Overview

This project focuses on analyzing Twitter data and classifying tweets into positive, negative, or neutral sentiments using Natural Language Processing (NLP) and machine learning techniques.

The goal was to transform raw Twitter text into meaningful numerical features, train classification models, evaluate their performance, and identify patterns in public opinion expressed through tweets.

🎯 Objectives

- Classify tweets into positive, negative, or neutral sentiments.
- Apply NLP techniques to clean and prepare Twitter text data.
- Convert tweets into meaningful machine learning features using TF-IDF.
- Compare different classification models and evaluate their performance.
- Generate visual insights from Twitter sentiment data.
- Demonstrate how sentiment analysis can support public opinion analysis, customer feedback analysis, and social media monitoring.

🔎 Key Steps

1. 📂 Data Exploration

Loaded and explored the Twitter dataset to understand its structure and sentiment distribution.

2. 🧹 Text Preprocessing

Preprocessed tweets by:

- Converting text to lowercase
- Removing punctuation
- Removing stopwords
- Tokenizing the text

3. 🔢 Feature Extraction

Applied TF-IDF Vectorization to transform tweet text into numerical features suitable for machine learning.

4. ✂️ Data Splitting

Split the dataset into 80% training data and 20% testing data.

5. 🤖 Model Training

Trained and compared two classification models:

- Naive Bayes
- Logistic Regression

6. 📊 Model Evaluation

Evaluated model performance using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrices

7. ☁️ Data Visualization

Created sentiment distribution charts and WordClouds to visualize common words across different sentiment classes.

8. 🔍 Error Analysis

Examined incorrectly classified tweets to understand areas where the models experienced difficulties.

9. 🏆 Model Comparison

Compared the classification models, identified the best-performing model, and explored how Twitter sentiment analysis can be applied to understand public opinion.

📈 Model Performance

The models were evaluated using standard classification metrics, including accuracy, precision, recall, and F1-score.

Logistic Regression achieved the better overall performance compared with Naive Bayes.
